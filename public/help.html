Что такое PoI и зачем это нужно

PoI (Proof of Intelligence) — это не казино и не букмекерская контора. Это система измерения интеллекта через реальные экономические ставки.

Традиционные платформы вознаграждают удачу. PoI вознаграждает знание. Участник, который систематически делает правильные предсказания, накапливает Proof of Intelligence — криптографическое доказательство своего интеллекта, записанное в блокчейне навсегда.

Для регуляторов: Система не является азартной игрой. Размер ставки не определяет вероятность выигрыша — её определяет точность предсказания.

Платформа полностью децентрализована. Нет центрального сервера, нет владельца, нет возможности манипулировать результатами. Код открыт, смарт-контракты верифицированы в блокчейне.

⚡

Преимущества перед традиционными рынками

  • ✅
    Нет маржина букмекера. Традиционные букмекеры берут 5-15% с каждой ставки. Здесь нет букмекера — рынок самофинансируемый. Комиссия только 0.5% с выигрыша.
  • ✅
    Нет спреда. На традиционных биржах предсказательных рынков есть непрерывный стакан со спредом bid/ask. Даже спред в 1-2 цента = 10-20% потерь. Все ордера за временной интервал собираются в пакет (batch) и исполняются по единой клиринговой цене — спред полностью исчезает.
  • ✅
    Нет маркет-мейкеров. Нет посредников которые зарабатывают на разнице цен. Цены определяются алгоритмом из реальных ордеров участников.
  • ✅
    Полное самофинансирование. Все деньги участников остаются в системе. Выигрыши выплачиваются из проигрышей.
  • ✅
    Proof of Intelligence. Правильные предсказания записываются в блокчейн навсегда. Это репутация которую нельзя купить, продать или подделать.
  • ✅
    Децентрализация. Нет компании которую можно закрыть. Нет сервера который можно взломать. Нет владельца который может заморозить ваши средства.
  • ✅
    IoT страхование без страховых компаний. Параметрическое страхование через смарт-контракты. Автоматическая выплата по данным датчиков без бюрократии.

Формулы самофинансирования

Система полностью самофинансируемая — выигрыши выплачиваются из общего пула ставок. Цены состояний определяются следующими формулами:

Pi = Ti / (M − ΣYi)
ΣPi = 1
  • Pi — цена состояния (вероятность исхода i)
  • M — общий пул (сумма всех ставок)
  • Ti — Pool Bet на исход i (только LP и seed)
  • Yi — Fix Bet на исход i (обычные участники)

Условие ΣPi = 1 гарантирует что сумма всех вероятностей всегда равна 1.

Proof of Intelligence (PoI) и Proof of Conviction (PoC)

Proof of Intelligence (PoI) — Доказательство интеллекта

PoI накапливается за каждое правильное предсказание. Чем менее очевидный исход вы предсказали правильно — тем больше PoI получаете.

PoI = log(1/p) − E[log(1/p)]

где p — рыночная цена исхода в момент вашей ставки. Категории: Спорт, Финансы, Политика, Погода, Редкие события.

Proof of Conviction (PoC) — Доказательство убеждённости

PoC объединяет интеллект со шкурным интересом. В теории игр этот принцип решает проблему асимметрии стимулов — «поставь шкуру на кон».

PoC = √stake × PoI

Квадратный корень предотвращает плутократию: удвоение ставки даёт лишь 40% прироста веса.

Зачем нужны PoI и PoC?

1. Право участвовать — без PoI NFT нельзя ставить ордера.

2. Право голосовать — голосование в DisputeOracle взвешено по PoC. Ваш голос весит пропорционально вашему доказанному интеллекту.

3. Верифицированное резюме — PoI NFT это доказательство аналитических способностей в блокчейне навсегда. Нельзя купить или подделать. Можно показать работодателям как доказательство качества прогнозов.

Важно: PoI не начисляется Liquidity Provider — LP ставит на все исходы и не делает прогнозов.

31 декабря каждого года — если в Treasury остаются средства после всех расходов, топ-3 по PoC получают 70% остатка поровну. 30% переходит на следующий год.

Регистрация — PoI NFT (Soulbound Token)

Для участия необходимо зарегистрироваться — минтить PoI NFT. Без NFT невозможно поставить ни одного ордера.

PoI NFT — нетрансферируемый токен (Soulbound Token). Его нельзя продать, передать или подделать. Привязан к вашему адресу навсегда.

Что записывается в NFT:

  • 📊 PoI по категориям: Спорт, Финансы, Политика, Погода, Редкие события
  • 💪 PoC score
  • 🔑 Адрес кошелька
  • 📅 История предсказаний — обновляется автоматически после каждого правильного прогноза
Защита от клонов: NFT привязан к конкретным адресам смарт-контрактов. Даже если кто-то скопирует весь код — ваш PoI остаётся только в оригинальных контрактах.

Как ставить ордера

Минимальная ставка: эквивалент $1 в ETH. Short продажи запрещены. Продавать можно только позиции которые уже куплены, и только после первого batch.

Только Fix Bet для обычных участников. Pool Bet доступен только для Liquidity Provider.

Fix Bet (Лимитный ордер) Для участников

Вы указываете исход и минимальную цену. Если рыночная цена при клиринге выше вашего лимита — ордер отклоняется и депозит возвращается.

Pool Bet (Рыночный ордер) Только LP

Ставка на все исходы пропорционально текущим ценам. Доступен только для Liquidity Provider.

  1. Откройте Arweave ссылку в браузере — установка не нужна. Работает на телефоне и компьютере.
  2. Подключите Web3 кошелёк (MetaMask, Rabby, Coinbase Wallet или любой другой)
  3. Зарегистрируйтесь — минтите PoI NFT ($0.79 крипто, разово навсегда)
  4. Выберите маркет и исход
  5. Укажите сумму (минимум $1 в ETH) и лимитную цену (от 0 до 1)
  6. Подтвердите в кошельке
  7. Ждите клиринга — происходит автоматически

Liquidity Provider (LP)

LP обеспечивает начальную ликвидность рынка. Ставит на все исходы одновременно пропорционально текущим ценам через Pool Bet.

Как стать LP:

Нажмите кнопку "Стать LP" в интерфейсе. Система автоматически распределит вашу ставку на все исходы.

Вознаграждение LP:

LP всегда выигрывает на одном исходе (правильном) и проигрывает на остальных. Выигрыш зависит от размера пула (паримутюэль), а не фиксированный. Дополнительно LP получает 0.1% от объёма своих ставок (максимум $100 за batch) как премию за ликвидность.

Риск LP:

Потери на проигравших исходах могут превысить выигрыш на правильном исходе плюс премию 0.1%.

Что НЕ получает LP:

  • ❌ PoI — LP не делает прогнозов
  • ❌ PoC — не начисляется
  • ❌ Право голоса в DisputeOracle
  • ❌ LP не запускает клиринг

Клиринг — как работает batch

Клиринг — процесс определения рыночных цен и распределения выигрышей. Использует алгоритм основанный на математических работах по теории предсказательных рынков.

Когда запускается batch?

Необходимо минимум 10 реальных ордеров (не считая LP и seed) на каждый из двух любых исходов. Это универсальное правило для любого количества исходов:

Количество исходовУсловие запускаМинимум ордеров
2 исходаОба исхода должны быть покрыты10 + 10 = 20
3 исходаЛюбые 2 из 3 покрыты10 + 10 = 20
5 исходовЛюбые 2 из 5 покрыты10 + 10 = 20
5+ исходовЛюбые 2 исхода покрыты10 + 10 = 20
Важно: Маркет считается состоявшимся только если произошёл хотя бы один batch. Финальный резолв без batch не выплачивает выигрыши.

Seed-ордера

При создании маркета AI агент размещает начальные ордера с вероятностями из открытых источников. Seed обеспечивает начальную ликвидность, но не запускает клиринг.

AI Агенты

Каждый агент запускается локально участниками сети — централизованного сервера нет.

market_creator_agent.py

Создаёт маркеты из одобренных событий. Получает начальные вероятности из открытых источников. Нормализует и размещает seed ордера.

distortion_agent.py Платный

Анализирует рыночные цены и находит переоценённые и недооценённые исходы. Не торгует — только предоставляет анализ участнику.

node.py

Основной узел сети. Автоматически следит за ордерами, запускает клиринг, записывает результаты, обновляет PoI и PoC.

blocking_agent.py

AI-модератор. Проверяет новые события на спам, манипуляции, неоднозначность. Блокирует некачественные маркеты.

iot_agent.py

Собирает данные IoT сенсоров, сравнивает с официальными источниками, применяет консенсус 3 из 5. Выявляет манипуляции.

resolver_agent.py

Автоматически резолвит маркеты после событий из официальных источников.

weather_agent.py

Данные о погоде из открытых источников. Контрольный источник для IoT сенсоров.

annual_bonus.py

Запускается 31 декабря. Распределяет 70% остатка Treasury между топ-3 по PoC. 30% → следующий год.

Система диспутов

Если вы не согласны с результатом — у вас есть 24 часа чтобы оспорить.

  1. Нажмите "Dispute" — доступно для resolved маркетов. Стоимость: 0.01 ETH.
  2. Голосование 24 часа — участники с PoI NFT голосуют. Вес = PoC.
  3. Финализация — любой вызывает finalizeDispute после 24 часов.
  4. Вознаграждение — 0.01 ETH распределяется между проголосовавшими пропорционально PoC.
Важно: LP не могут голосовать в диспутах — их PoC = 0.

IoT — Параметрическое страхование

Фермер, рыбак, владелец склада может застраховаться от природных катастроф без страховой компании. Выплата происходит автоматически по данным IoT сенсоров.

Защита от манипуляций с датчиками

Консенсус минимум 3 из 5 независимых сенсоров. AI агент выявляет манипуляции: прикладывание льда, размещение на солнце, физическое воздействие, аномальные отклонения.

Первое нарушение: данные исключаются из события.
Второе нарушение: аккаунт заблокирован навсегда.

Как зарегистрировать сенсор

Поддерживаются устройства с WiFi API (Shelly, ESP32, Arduino). Запустите iot_agent.py и зарегистрируйте с координатами. Каждое использование данных = 0.001 ETH автоматически.

Обычному участнику запускать node не нужно. Просто ставьте ордера — node операторы сделают клиринг автоматически.

Изменения в платформе принимаются только через голосование топ-50 участников по PoC с 80% большинством. Никто единолично не может изменить правила. Предложение изменения: создайте Issue в репозитории с описанием и обоснованием.
